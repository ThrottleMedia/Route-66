TWO LANES & A THOUSAND STORIES — ROUTE 66 WEBSITE

OPENING THE WEBSITE
1. Extract route66-roadtrip.zip.
2. Open the route66-roadtrip folder.
3. Open index.html in Chrome, Edge, Safari or Firefox.

PUBLISHING WITH GITHUB PAGES
1. Create a new GitHub repository (or use an existing website repository).
2. Upload index.html to the root of the repository.
3. In Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
4. GitHub will provide your public website URL.

NOTES
- The bucket-list ticks and journal entries save in the browser on the device being used.
- The trip planner can generate and copy a simple trip summary.
- Google Fonts require an internet connection; the rest of the page is self-contained.
- Check attraction opening times, road conditions, entry requirements and reservations before travel.
